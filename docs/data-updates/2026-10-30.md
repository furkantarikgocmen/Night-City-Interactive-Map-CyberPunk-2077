## New location details

### Phantom Liberty job chain

The seven new Dogtown main jobs include upstream previous/next links, allowing the popup navigation to follow this quest sequence:

`The Damned` → `Get It Together` → `You Know My Name` → `Birds With Broken Wings` → `I've Seen That Face Before` → `Firestarter` → `Run This Town`

The upstream sequence currently skips from `You Know My Name` directly to `Birds With Broken Wings`; that ordering is preserved exactly as published.

### 1057588 — Page of Swords

The description places the tarot card inside Clouds on Level 12 of Megabuilding H8.

### Vehicle contracts

All six vehicle contracts contain upstream tag `119` but currently have no text descriptions or media.
