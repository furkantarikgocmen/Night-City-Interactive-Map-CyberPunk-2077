## Marker sprite changes

The upstream marker sprite changed to `markers/v11/markers@2x.png` with dimensions `462 × 578`. The previous local sprite and CSS covered only `462 × 528` (`231 × 264` CSS pixels).

Several shard-style categories now reference a new icon row beginning at CSS offset `y = 264`. Updating only the JSON files left those icons outside the old local sprite bounds and also shifted the Glamdoc and Easter Egg icons.

Resolution:

- Replaced the old local WebP with the upstream v11 PNG sprite.
- Added `markerSpriteWidth` and `markerSpriteHeight` to the generated map metadata.
- Made the frontend derive map and sidebar sprite dimensions from that metadata.
- Updated the data updater to discover, download, dimension-check, compare, and atomically replace the public sprite.
- Increased frontend and data cache versions.
- Confirmed that Glamdoc, Easter Egg, sidebar shard, and map shard icons render correctly after rebuilding the containers.
